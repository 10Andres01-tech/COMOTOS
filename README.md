# Comotos - Plataforma Web de Motocicletas

Este proyecto es una plataforma interactiva construida en **React** basada en la interfaz y diseño wireframe de Comotos.

## 🚀 Características principales
- **Navegación SPA por pestañas**: Inicio, Motos, Comparador, Favoritos y Estadísticas.
- **Manejo de estado reactivo**: Marcado de favoritos y selección para comparación en tiempo real.
- **Filtros por categoría y buscador**: Filtrado ágil de productos.
- **Sistema de Autenticación**: Modales de Login y Registro.
- **Estilos modulares CSS**: Hoja de estilos independiente `styles.css` con la paleta de colores personalizada.

## 🛠️ Instalación y Ejecución

1. Descarga e descomprime el archivo `.zip`.
2. Abre la terminal en el directorio del proyecto y ejecuta:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
